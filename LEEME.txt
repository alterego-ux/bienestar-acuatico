BIENESTAR ACUÁTICO — NEON AQUACULTURE
=====================================

Proyecto académico basado en la metodología ICA v2.0 (2024). No es un sistema oficial del ICA.

MODO 1 · SOLO FRONTEND (rápido)
  Abre index.html con doble clic. Es una aplicación web (HTML/CSS/JS) que guarda los datos en
  localStorage e IndexedDB. No necesita backend ni base de datos.

MODO 2 · CON BACKEND (Node.js + Express + PostgreSQL)
  1) Levanta PostgreSQL:  docker compose up -d      (o usa tu PostgreSQL local)
  2) cd backend
     Copy-Item .env.example .env                    (cp en Linux/macOS)
     npm install
     npm run setup                                  (crea tablas + siembra catálogos y datos demo)
     npm start                                       -> http://localhost:4000
  3) Abre http://localhost:4000/  ·  estado de la API: /api/salud
  Detalle completo en backend/README.md.
