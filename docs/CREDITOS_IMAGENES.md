# Créditos y licencias de imágenes

La portada de Angular utiliza las fotografías locales existentes y una galería ampliada. Varias imágenes de la galería se solicitan desde Wikimedia Commons y USFWS; requieren conexión a Internet. La terminal de este entorno no pudo resolver dominios externos, por lo que no fue posible guardar los originales externos como archivos locales durante esta edición. Si una imagen remota no carga, la interfaz cambia a una fotografía local de referencia y actualiza el pie de imagen para no presentar la especie o el sistema como si la fotografía alternativa fuera la original. Para una entrega completamente offline, descarga los archivos desde las fichas enlazadas, verifica su licencia y reemplaza las URL de la galería por rutas bajo `frontend-angular/public/Im/`.
